# 拼音词语大冒险

四年级上册（1-8单元）看拼音写词语记忆游戏，帮助小朋友高效复习期末词语。

## 功能特色

- **学习模式** — 按单元认识新词语，带提示功能
- **记忆复习** — 基于艾宾浩斯遗忘曲线的间隔重复算法，智能安排复习
- **错题本** — 自动记录答错的词语，支持专项攻克
- **终极考验** — 随机抽题挑战，检验学习成果
- **学习统计** — 学习时长、词语掌握率、各单元进度、近7日学习记录
- **记忆曲线** — 可视化展示未学/学习中/复习中/已掌握分布

## 使用方法

1. 用浏览器打开 `index.html` 即可使用（无需安装）
2. 所有学习数据保存在浏览器本地，不会丢失（除非清除浏览器数据）
3. 在「设置」页面可选择练习的单元和调整考验题数

## 本地运行

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 技术说明

- 纯前端 HTML/CSS/JavaScript，无需后端
- 数据存储在 localStorage
- 间隔重复算法：1天 → 2天 → 4天 → 7天 → 15天 → 30天 → 60天

## 词语来源

词语内容基于部编版四年级上册语文 1-8 单元词语盘点整理。如需导入 docx 文件中的自定义词语，可编辑 `js/data.js` 添加。
