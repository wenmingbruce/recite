# 单词星球 🌟

> 人教版小学5年级英语单词记忆游戏

一款专为小学5年级学生设计的英语单词记忆游戏，基于艾宾浩斯记忆曲线（SM-2间隔重复算法），帮助孩子科学、高效地记忆单词。

## 功能特性

- **🎯 三种游戏模式**
  - 选择题：四选一，选出正确的中文意思
  - 拼写：根据发音和中文提示，输入英文单词
  - 配对：将英文单词与中文意思连线匹配

- **🧠 记忆曲线系统**
  - 基于 SM-2 间隔重复算法
  - 根据答题表现智能调整复习时间
  - 答对越多，下次复习间隔越长

- **📖 错题本**
  - 自动记录答错的单词
  - 支持专项练习错题
  - 可标记已解决的错题

- **📊 学习统计**
  - 每日学习时长
  - 单词掌握数量
  - 连续学习天数
  - 近7天学习图表
  - 各单元掌握情况

- **📚 单词表**
  - 人教版5年级上下册全部单词
  - 含音标、例句
  - 可按单元筛选
  - 显示掌握状态

## 单词范围

涵盖人教版小学英语5年级上下册共12个单元，约100个核心词汇：

| 册次 | 单元 | 主题 |
|------|------|------|
| 上册 | Unit 1-6 | 老师描述、星期、食物、家务、动物、自然 |
| 下册 | Unit 1-6 | 未来职业、日常活动、天气、月份、地点、交通方向 |

## 技术栈

- **React 19** + TypeScript
- **Vite** 构建工具
- **Tailwind CSS v4** 样式
- **Lucide React** 图标
- **localStorage** 数据持久化（无需后端）

## 开发运行

```bash
cd word-game
npm install
npm run dev
```

访问 http://localhost:5173

## 构建部署

```bash
cd word-game
npm run build
# dist/ 目录即为静态文件，可直接部署到任何静态托管服务
```
