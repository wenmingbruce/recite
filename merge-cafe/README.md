# 甜蜜旅程 Sweet Journey Cafe

一款女性向二合（Merge-2）休闲游戏，参考 Tasty Travel 玩法与 Homescapes 美术风格。

## 玩法

- **合并**：拖动两个相同的物品到一起，合成更高级的物品
- **生成**：点击咖啡机 / 烤箱 / 旅行柜台，消耗体力生成新物品
- **订单**：完成顾客订单获得金币和经验
- **升级**：积累经验升级，解锁更多装饰

## 物品链

| 主题 | 合并路径 |
|------|----------|
| ☕ 咖啡 | 🫘 → ☕ → 🥤 → 🧋 → 👑 |
| 🧁 甜点 | 🌾 → 🍪 → 🧁 → 🎂 → 💎 |
| ✈️ 旅行 | 🎫 → 📮 → 🧳 → ✈️ → 🌍 |

## 运行

```bash
cd merge-cafe
python3 -m http.server 8081
# 访问 http://localhost:8081
```

iPad / 手机浏览器均可游玩，支持触屏拖拽。

## 特色

- 粉紫色调女性向 UI，Homescapes 风格咖啡馆场景
- 顾客订单 + 剧情对话
- 本地存档（localStorage）
- 体力自动恢复（每 3 分钟 +1）
